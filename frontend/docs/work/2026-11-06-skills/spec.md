# 기획서: 디자인 스킬 · 움직임 9가지 · SEO · 보안 (2026-11-06)

Matt Pocock 작업 순서(질문 → 기획서 → 일감 → 코드 → 리뷰 두 번 → 회고)를 따른다. 질문은 4기 Organizer 이도윤에게 두 번 받았다.

## 문제 (방문자 쪽에서)
- 화면 곳곳에 'AI가 만든 화면' 티가 남아 있다: 제목 위 작은 이름표, '·'로 이어 붙인 정보 줄, 링크 뒤 화살표, 사진 밑 설명, 글자로 그린 아이콘.
- 움직임이 이름 없이 섞여 있다. 열리고 닫히는 곡선 · 시간이 곳마다 다르고, 카드가 창이 될 때 이어지는 느낌이 없다.
- 주소를 공유하면 어느 주소든 홈 제목 · 설명 · 공유 카드가 뜬다 (카카오톡 · 인스타 DM 미리보기는 자바스크립트를 돌리지 않는다).
- 보안 헤더가 없어 다른 사이트가 우리 페이지를 iframe 으로 감쌀 수 있고, 글꼴 CSS 를 바뀔 수 있는 주소에서 받는다.

## 해결 (방문자 쪽에서)
- 세 디자인 스킬(hallmark · impeccable · taste-skill)의 바닥 규칙을 지킨다. dcamp 모양과 부딪히면 스킬 규칙이 이긴다 (Leo 결정).
- 움직임은 9가지 이름으로만 쓴다: 이즈 인 · 이즈 아웃 · 스프링 · 바운스 · 순차 등장 · 페이드 · 슬라이드 · 확대 전환 · 공유 요소 전환. 자리마다 하나.
- 주소마다 자기 제목 · 설명 · 공유 카드를 가진 HTML 을 내보낸다. 사이트맵 · canonical · 구조화 데이터를 둔다.
- vercel.json 에 보안 헤더를 넣고 글꼴 CSS 는 고정 버전 주소 + 무결성 해시로 받는다.

## 사용자 이야기
1. 지원자로서, 링크를 친구에게 보내면 '지원하기' 페이지의 제목 · 설명이 미리보기에 뜨길 원한다. 그래야 친구가 무슨 링크인지 안다.
2. 방문자로서, 제목이 제 무게로 읽히길 원한다 (위에 작은 영문 이름표 없이).
3. 방문자로서, 날짜 · 장소 · 종류를 '·' 줄이 아니라 칸이나 줄로 나눠 읽고 싶다.
4. 방문자로서, 프로젝트 카드를 누르면 그 카드가 그대로 커져 자세히 보기 창이 되길 원한다 (어디서 열렸는지 안다).
5. 방문자로서, 창 · 메뉴 · 미리보기가 열릴 때는 빠르게 들어오고 닫힐 때는 더 빨리 빠지길 원한다.
6. 폰 방문자로서, 메뉴 시트가 오른쪽에서 밀려 들어오길 원한다.
7. 방문자로서, 페이지마다 한 곳에서만 카드가 차례로 나타나길 원한다 (전부 움직이면 정신없다).
8. 움직임 줄이기를 켠 방문자로서, 모든 움직임이 멈추고 내용은 처음부터 다 보이길 원한다.
9. 스크립트가 꺼진 방문자로서, 내용이 숨지 않길 원한다.
10. 키보드 사용자로서, 초점 표시가 바로 보이길 원한다.
11. 운영진으로서, 검색 결과에 관리자 화면과 예시 글이 나오지 않길 원한다.
12. 운영진으로서, 옛 주소(/projects · /community)가 검색에서 새 주소로 넘어가길 원한다.
13. 방문자로서, 다른 사이트가 우리 페이지를 감싸 비밀번호 칸을 가로채지 못하길 원한다.
14. 다음 작업자로서, 이 사이트의 말(기수 · 코어 멤버 · G-Sprint · 검정 띠 …)을 한 단어장에서 찾고 싶다.

## 구현 결정
- 움직임 토큰 (tokens.css): `--ease-out`(도착) · `--ease-in`(나감) · `--ease-in-out`(토글) · `--ease-spring`(CSS linear() 로 근사, 살짝 넘쳤다 멈춤) · `--ease-bounce`(통통 한 번), `--dur-micro` 120 · `--dur-short` 220 · `--dur-long` 420. 나감은 들어옴의 60–75%. 순차 등장 간격 40ms, 다 합쳐 500ms 이하, 한 번.
- 움직이는 것은 transform · opacity 만 (hallmark 10a). `transition: all` 금지.
- 순차 등장은 페이지마다 한 곳. 기본은 보이는 상태이고, 스크립트가 IntersectionObserver 로 '아직 안 봄' 표시를 붙였다 뗀다 (스크립트 꺼짐 · 움직임 줄이기면 그냥 보임).
- 확대 전환 · 공유 요소 전환: View Transitions API(`document.startViewTransition`) 로 카드 표지 그림과 창 그림에 같은 `view-transition-name` 을 준다. 지원하지 않는 브라우저는 창이 카드 자리에서 커지는 확대 전환만.
- 스프링 · 바운스는 hallmark 12(UI 상태에 넘침 금지)를 기록하고 넘긴다(waive): Leo 가 움직임 9가지를 직접 골랐다. 자리는 토글 손잡이 · 지도 미리보기(스프링), '지금' 이름표와 그 줄의 구름(바운스) 셋으로 한정.
- 날짜 범위는 '~' (hallmark 19: en/em dash 금지). docs/CONTENT.md 규칙도 바꾼다.
- 주소별 HTML: 빌드 뒤 스크립트(scripts/route-html.mjs)가 dist/index.html 을 dist/<route>.html 로 복사하며 title · description · og · canonical 을 바꾸고, vercel.json cleanUrls 로 /<route> 에 내보낸다 (만들며 바꿈 2026-11-06). 문구는 src/content/seo.json (탭 제목은 usePageTitle 과 같게).
- 보안 헤더: CSP(default-src 'self', 글꼴 · 스타일 출처만 허용, frame-ancestors 'none'), nosniff, Referrer-Policy.

## 테스트 결정
- 겉으로 드러나는 동작만 시험한다: 주소별 HTML 의 title · description · canonical 값(빌드 산출물 읽기), 사이트맵 주소 목록, 날짜 범위 표기 함수, 순차 등장 훅이 움직임 줄이기에서 아무것도 숨기지 않는지.
- 앞선 예: content.test.ts(콘텐츠 규칙), seminars.test.ts(표기), timeline.test.ts.
- 화면은 Playwright 스크린샷 · axe · 가로 넘침 검사 · hallmark sloplint(정적)로 본다.
